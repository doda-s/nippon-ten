## Problema

1. Ele não tem site institucional e para vendas
2. O custo do Ifood está alto (26%) sobre o valor
3. Não tem sistema de fidelidade ou pontos
4. Trazer cliente de volta para o estabelecimento físico
5. Sem delivery próprio (Aplicativo/aplicação web)
6. Dificuldade em centralização de todos os pedidos
7. Gestão dos sistemas de bonificação

## Escopo

1. Poder fazer pedido pelo site
2. Permitir fazer pedidos sem cadastro
3. Ter dashboard de gerenciamento para usuários internos
4. Dashboard para mostrar histórico de vendas
5. Dashboard para acompanhar pedidos e seus estados
6. O Dashboard deve atualizar os estados (pendente, em preparo, finalizado)
7. Dashboard para usuários internos, onde eles consigam verificar usuários pelo cpf/nome/telefone e realizar
pedidos no local
8. Mostrar a quantidade de pontos que o usuário possui
9. Opção para o usuário realizar pedido no local
10. Permitir cadastro de usuários (Login)
11. Permitir usuário editar suas informações
12. Permitir recuperar senha.
13. Sistema precisa solicitar dados mínimos para realizar entrega. Nome completo e endereço
14. O usuário deve poder visualizar histórico de compras e pedidos
15. O sistema deve permitir os usuários internos criarem produtos
16. O sistema deve permitir os usuários internos editarem os produtos
17. O sistema deve permitir os usuários internos deletearem os produtos
18. O sistema deve permitir listar os produtos.
19. O sistema deve permitir os usuários internos adicionarem ingredientes
20. O sistema deve permitir os usuários internos editarem os ingredientes
21. O sistema deve permitir os usuários internos deletarem os ingredientes
22. O sistema deve permitir listar os ingredientes
23. O sistema deve permitir os usuários internos definirem ingredientes como esgotados
24. O sistema deve permitir os usuários internos criarem promoções de diversos produtos
25. O sistema deve permitir os usuários internos editarem as promoções criadas
26. O sistema deve permitir os usuários internos deletarem as promoções criadas
27. O sistema deve permitir os usuários internos definirem o tempo que uma promoção fica disponível
28. O sistema deve permitir listar as promoções existentes
29. O sistema deve permitir os usuários internos a criarem combos com um ou mais produtos
30. O sistema deve permitir os usuários internos editarem os combos existentes
31. Os combos devem ter no mínimo dois produtos
32. O sistema deve permitir os usuários internos deletarem combos
33. O sistema deve permitir os usuários internos dedfinirem o tempo que um combo fica disponível
34. O sistema deve permitir os usuários internos criarem cupons
35. O sistema deve permitir os usuários internos definirem o tempo que um cupon fica disponível
36. O sistema deve permitir os usuários internos administradores configurarem a conversão de dinheiro gasto, em pontos.
37. Os usuários internos administradores devem conseguir ver o impacto que a configuração de conversão de dinheiro em pontos tem
38. Os usuários internos devem ter cargos com permissões diferentes de acesso e responsabilidades
39. Os usuários devem conseguir deletar suas próprias contas
40. Os usuários devem conseguir criar pedidos
41. Os usuários devem conseguir cancelar pedidos ativos
42. Os usuários devem conseguir ver seus pedidos ativos
43. Os usuários internos devem conseguir editar pedidos ativos
44. Os usuários devem conseguir adicionar observações nos pedidos
45. Os usuários deve conseguir adicionar ou remover, bem como alterar os ingredientes dos pastéis, nos pedidos
46. Os usuários devem conseguir visualizar o carrinho de compras
47. Os usuários devem conseguir pesquisar por produtos
48. Depois do pedido ser entregue, o sistema deve solicitar pelo feedback dos usuários
49. O sistema deve informar ao usuário quando o pagamento é realizado
50. O sistema deve informar ao usuário quando o pedido sai para a entrega
51. O sistema deve informar ao usuário quando um pedido é cancelado
52. O cliente deve conseguir pagar pelo produto diretamente pelo sistema
53. O sistema deve limitar a quantidade de adicionais que o cliente pode colocar no pedido
54. Produtos que dependem de um ingrediente marcado como esgotados, devem ficar indisponíveis
